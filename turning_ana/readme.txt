The "turning_ana" folder contains customized code for plotting data in Figs. 6 and 7, and Figs. S12 and S14. "turning_DLC.m" and "turning_DLC_GC.m" are the main functions. Portions of this code were generated with assistance from Claude by Anthropic.

TDMS reader is downloaded from https://www.mathworks.com/matlabcentral/fileexchange/30023-tdms-reader

## instructions

Run ‘turning_DLC’
1. Load trigger times file
2. Load tracks getting from deepLabCut
3. Set cmpp and other parameters
4. Click ‘turning_DLC’ to analyze the data and get the figure


Run ‘turning_DLC_GC’
1. Load the EVENT file first and then the GCaMP signal. You can get the 
     Trial number in the command window.
2. Load video
3. Read LED onset. It may take several minutes. You will get the trial
   Number of LED onsets in the command window. Make sure this number
   Is the same as trial number in fiber photometry system. If not,
   Try adjusting LEDthre and then click ‘LED_recheck’. You will get a csv file
   Named ‘trigger_times_led.csv’.
4. In case you want to adjust LEDthre to get the precise LED onset
5. Load the LED onset file named trigger_times generated by clicking
   ‘LED read’
6. Load tracks getting from deepLabCut
7. Get turning events. This step may take over one minute.
8. Click ‘turning_gc’ to analyze the data and get figures. 
9. Example plotting. 
There will be some basic output information in the command window 
for some of the steps. An output file will be saved in the end.
